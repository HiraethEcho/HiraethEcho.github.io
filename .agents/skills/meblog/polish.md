# Polish — 润色校对

轻量润色，**仅限**错别字、病句、标点符号。不改语气/结构/风格/术语/文化引用/markdown 格式。

## 检查清单

顺序：标点 → 空格 → 错字/病句。

### 标点
- 中文句内全角：`。，、！？：；“”（）《》`
- 完整英文句内半角
- 不重复：不写 `！！`、`？？！！`
- 省略号 `……`（6 点），不用 `。。。` 或 `...`
- 书名号 `《》`，不用引号代替
- 行内代码内的标点保留原样

### 空格
- 中英文间加空格：`一段 English 文本`
- 中文与数字间加空格：`2024 年的数据`
- 全角标点与中文/英文间**不加**：`内容：Apple`、`包含 HTML、CSS`
- 数字与单位间不加：`75kg`、`$85`
- 行内代码前后加空格：``参数 `foo` 表示``

### 错别字与病句
- 形近/音近错别字
- 主语缺失、搭配不当、句式杂糅
- "的/地/得"混用（明显时）
- 量词错误
- 不改个人风格化表达

## 工作流

1. 读取文章（跳过 frontmatter）
2. 逐段按清单校对，最小修改
3. 输出修改摘要

### 摘要格式

```markdown
## 修改摘要

### 标点修正
- `行号`：原内容 → 修改后（原因）

### 空格修正
- 同上

### 错别字/病句修正
- 同上

### 建议人工确认
- `行号`：标记内容（原因）
```

## 补充

润色完后调用 `suggest-meta` 补充 frontmatter 元信息。
