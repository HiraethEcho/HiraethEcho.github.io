# Brainstorm — 选题与构思

从素材中提炼可用的写作选题。

## 工作流

### 1. 读取素材
扫描 drafts/ 下的相关文章，寻找可发展的素材。

### 2. 分析素材
对每个有价值的素材，提取：
- **核心观点** — 在说什么
- **可发展的方向** — 能写成 essay/memo/note
- **关联素材** — 与其他素材的联系
- **潜在 taxonomy** — categories, topics, series

### 3. 输出选题

```markdown
## 选题 N: <标题>

**来源**: drafts/xxx.md
**类型**: essay | memo | note
**核心观点**: 一句话概括
**发展思路**: 2-3 句
**关联**: 与已有文章的联
**建议 taxonomy**: categories=, topics=, series=
```

### 4. 交互确认
列出 3-5 个最有潜力的选题 → 问用户兴趣 → 深入讨论选定的。

## 注意事项

- 优先最近添加的素材
- 注意素材间交叉主题
- 素材不足时建议用户补充
- 不强推素材成文
