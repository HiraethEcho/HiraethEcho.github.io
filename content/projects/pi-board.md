# Pi Board

用隐喻方式描述，就是和模型在一块黑板上讨论论文，可以指着一块板书或者论文中的一段，问它这是怎么个事。  
通过浏览器前端显示，仿照 pdf 编辑器加注释的方式引用片段，包括对文件的修改，用 diff 格式说明。
把这些组装成一段 prompt，并且可以追加说明等，发送给模型。

基本理念非常简单，实现方式也很直接，没有对 `pi` 做专门设计，所以应该容易移植。  
另一个不做优化的原因是，我认为应该在模型层面对这种交互方式做后训练，从本质上修改「对话」这种间接方式。
