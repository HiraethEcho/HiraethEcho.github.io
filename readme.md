## philosophy 哲学背景

精神底色是存在主义与对现代性的批判。哲学在此不是学科，而是一种生活方式：**未经审查的人生不值得一过**——过一种不断自我审视的生活。文风基调：**悲观但不消极，保持愤怒**。写作动机见 [我存在！Es Muss Sein!](https://memex.keinmal.top/glade/essay/existence)。

### leanings 倾向

- **存在主义为底色，以反抗为行动纲领**（existentialism as ground, resistance as program）—— 从加缪《西西弗神话》开始：拒绝虚妄的意义与希望，也拒绝逃入死亡，选择永远反抗荒诞（[No!](https://memex.keinmal.top/glade/memo/No)、[存在主义入门](https://memex.keinmal.top/glade/essay/introexistentialism)）
- **现代性批判**（critique of modernity）—— 法兰克福学派（马尔库塞、阿多诺、本雅明）、情境主义（德波《景观社会》）、鲍德里亚《消费社会》、鲍曼、韩炳哲；兼及技术批判（GNU/RMS、反信息茧房、RSS）
- **反本质主义**（anti-essentialism）—— 忒修斯之船式的唯名论倾向：不存在可被属性挂靠的“实体”，人“是其所是”即其生存全部细节的总和（[我存在](https://memex.keinmal.top/glade/essay/existence)）

- **“只有一次等于没有”**（_einmal ist keinmal_，昆德拉引德语谚语）—— 永恒轮回这一极端想象带来的沉重与轻盈；域名 keinmal.top 即出于此（[只有一次等于没有](https://memex.keinmal.top/glade/memo/oneisnone)）
- **读书观**—— 反对入门书“给答案”（批评邓晓芒《哲学起步》）、反对权威式的主观说教（批评罗素《西方哲学史》）；怀疑语言表达复杂思想的能力（《我们赖以生存的隐喻》）
- **AI 立场有清晰边界**—— 个人随笔写作不用 AI（保护语言能力即保护思考能力）；知识获取可以借助 AI；代码开发重度使用 AI（vibe coding）。详见 [me](https://memex.keinmal.top/me) 的 Yep and Nope

## writing 写作

**动机**：焦虑、抑郁和荒诞激情促使我企图用某种方式消耗掉自己——"我要在我耗尽的过程中写下我自己，非这样不可"（[我存在！Es Muss Sein!](https://memex.keinmal.top/glade/essay/existence)）。表达欲与某种"创作的紧迫"构成了持续写作的动力；文化产品评论（书影音）像半命题作文，既有写作主题，又有发挥空间。风格基调：**悲观但不消极，保持愤怒**；自嘲自贬是常态；避免空洞漂亮话。

**博客体系**：[memex](https://memex.keinmal.top) 是一个五层结构的个人思维仓库（forest → morgue → glade → garden → diary）：

- **forest 森林** —— 原始素材：摘抄、剪藏
- **morgue 停尸房** —— 草稿坟场：idea、outline、未成形文本
- **glade 林中空地（Lichtung）** —— 成熟表达：essay 长文与 memo 短文
- **garden 知识花园** —— 外部习得后整理的知识
- **diary 日记** —— 私人时间线

**写作观**：

- 自己的文章不用 AI 生成或辅助润色（最多查错别字、病句）——**保护语言能力就是保护思考能力**（也有对 AI 写作的实践与讨论，见 memex 的 ai-lang 系列）
- 不为表达而议论不在场者的缺点（对方无法为自己辩护，这不公平）
- 写作类型体系：critique / introspection / kulturprodukte / mumble / philosophical / weblog / braindump / textbook，每种类型有一套风格约束（详见 [style.md](https://memex.keinmal.top/glade/essay/style)）

- [No!](https://memex.keinmal.top/glade/memo/No) —— 诗；读《西西弗神话》后的反抗宣言：拒绝意义与希望，拒绝逃入死亡，永远反抗荒诞
- [我存在！](https://memex.keinmal.top/glade/essay/existence)（Es Muss Sein!）—— 存在主义内省："我时刻塑造着我，非这样不可"
- [只有一次等于没有](https://memex.keinmal.top/glade/memo/oneisnone) —— 永恒轮回与一次性：每一种爱只有一次
- [存在主义入门](https://memex.keinmal.top/glade/essay/introexistentialism) —— 存在主义阅读线索
- [书单](https://memex.keinmal.top/glade/essay/books) —— 持续更新的短书评合集
